# 立体の可視化：(x − y)² + z² ≥ 1（0 ≤ x, y, z ≤ 1）

座標空間で、次の連立不等式が表す立体を 3D で見るための Web アプリです。チャート数学ⅢC　例題203

```
0 ≤ x ≤ 1,  0 ≤ y ≤ 1,  0 ≤ z ≤ 1
x² + y² + z² − 2xy − 1 ≥ 0
```

ブラウザ上で立体を回転させたり、断面を確認したり、モンテカルロ法で体積を確かめたりできます。

---

## 数学的な背景

### 式の変形

x² + y² − 2xy = (x − y)² なので、条件は次の式と同じです。

```
(x − y)² + z² ≥ 1
```

これは、直線 **x = y, z = 0** を軸とする半径 1 の円柱の**外側**です。
単位立方体の中では、この部分は頂点 (1, 0, 1) の近くと (0, 1, 1) の近くにある 2 つの塊になります。
2 つは平面 x = y について対称です。

### 断面

平面 z = k（0 ≤ k ≤ 1）で切ると、断面は次のようになります。

```
|x − y| ≥ √(1 − k²)
```

断面は合同な直角二等辺三角形 2 つです。直角をはさむ辺の長さは 1 − √(1 − k²) です。
したがって断面積は次のとおりです。

```
S(k) = (1 − √(1 − k²))²
```

### 体積

```
V = ∫₀¹ (1 − √(1 − k²))² dk
  = ∫₀¹ (2 − k² − 2√(1 − k²)) dk
  = 2 − 1/3 − 2 · (π/4)
  = 5/3 − π/2
  ≈ 0.09587
```

（∫₀¹ √(1 − k²) dk は半径 1 の四分円の面積 π/4 です。）

## 機能

| 機能 | 内容 |
|------|------|
| 3D 表示 | 立体をマウスで回転・移動・拡大縮小できます。曲面はオレンジ、平らな面は青で表示します。 |
| 円柱の表示 | 境界の円柱 (x − y)² + z² = 1 とその軸 (x = y, z = 0) を半透明で重ねて表示します。 |
| 立方体の枠 | 単位立方体を点線で表示します。表示・非表示を切り替えられます。 |
| 断面 z = k | スライダーで k を変えると、断面（黄色）が 3D と 2D の両方に表示され、断面積も出ます。 |
| 切り取り表示 | 立体のうち z ≤ k の部分だけを表示し、断面の形を立体の中で確認できます。 |
| モンテカルロ法 | 20 万点をランダムに打ち、条件を満たす点を赤で表示します。推定体積と理論値との誤差も出ます。 |

## 使い方

### 起動方法

1. `index.html` をダウンロードまたは保存します。
2. ブラウザ（Chrome、Edge、Firefox、Safari など）で `index.html` を開きます。

> **注意：** ライブラリ（Three.js）を CDN から読み込むため、インターネット接続が必要です。

ファイルを直接開いても表示されない場合は、ローカルサーバーを使ってください。

```bash
# Python がある場合
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### 操作方法

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 回転 |
| 右ドラッグ | 平行移動 |
| マウスホイール | 拡大・縮小 |
| スライダー | 断面の高さ k を変更（0 〜 1） |

### 画面の構成

- **左上のパネル**：表示の切り替え、断面スライダー、体積の理論値、モンテカルロ法のボタン
- **右下のパネル**：断面 z = k の 2D 図と断面積

## 使用技術

- [Three.js](https://threejs.org/) r160（3D 描画）
- OrbitControls（カメラ操作）
- HTML5 Canvas（断面の 2D 描画）
- ES Modules と Import Maps（ビルド不要）

### 実装の要点

- 座標系は数学の慣習に合わせ、**z 軸を上**にしています（`camera.up = (0, 0, 1)`）。
- 曲面は、x − y = sin θ、z = cos θ（0 ≤ θ ≤ π/2）とおいてパラメータ表示しています。
- 一方の塊を作ったあと、x と y を入れ替えて、もう一方の塊を作っています。
- 切り取り表示には Three.js のクリッピング平面（`localClippingEnabled`）を使っています。
